# CFMMC 期货交易复盘系统

中国期货市场监控中心（CFMMC）投资者查询系统 —— 数据抓取、结算单解析、Web 交互式复盘分析。

## 功能特性

- **数据抓取**：自动登录监控中心，下载逐日盯市 / 逐笔对冲 XLS 结算单（支持验证码自动识别）
- **智能解析**：兼容两种报表格式（逐日盯市 / 逐笔对冲），正确处理期货与期权成交汇总
- **Web 复盘平台**：Flask 前后端分离架构，浏览器中直接查看分析结果
  - 总览卡片：总盈亏（期货+期权）、分项明细、净盈亏
  - 品种盈亏纵览：按品种汇总手数/盈亏/手续费，支持排名
  - 每日累计趋势图
  - 品种详情弹窗（点击品种名）
  - TOP 盈亏成交排行

## 快速开始

### 环境要求

- Python 3.8+
- 依赖包：

```bash
pip install requests ddddocr xlrd pandas matplotlib openpyxl pillow beautifulsoup4 flask
```

### 配置账户

在项目根目录创建 `config.json`：

```json
{
  "accounts": [
    {
      "fund_name": "我的基金",
      "broker": "dw",
      "account_no": "你的账号",
      "password": "你的密码"
    }
  ],
  "start_date": "20260101",
  "end_date": "20261231",
  "output_dir": "./output"
}
```

> `broker` 为期货公司缩写（如 `dw`=东吴），`output_dir` 为下载文件的存储路径。

### 启动 Web 服务

```bash
python3 review_web.py
```

打开浏览器访问 **http://localhost:8869**，在页面内登录监控中心即可开始查询复盘。

### CLI 模式

```bash
# 交互式
python review.py

# 命令行指定日期范围
python review.py --start 20260401 --end 20260513
```

## 使用说明

1. **登录**：在 Web 页面输入期货账号和验证码登录监控中心
2. **选择日期范围**：支持"今日/本周/本月/上月/全部"快捷选择或自定义
3. **查询复盘**：点击"查询复盘"，系统会：
   - 自动检测缺失的交割单并下载
   - 解析 XLS 结算单（期货成交 + 期权成交，含权利金收支）
   - 计算总盈亏 = 期货平仓盈亏 + 期权 FIFO 已实现盈亏
   - 渲染图表和数据表格
4. **查看详情**：点击品种名称弹出该品种的所有成交明细

## 盈亏计算说明

| 指标     | 说明                                                                                                                                    |
| -------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| 期货盈亏 | 逐笔对冲报表中的平仓盈亏 / 逐日盯市报表中的当日盈亏                                                                                     |
| 期权盈亏 | **FIFO 开平仓匹配后的已实现盈亏**：同一合约内按先进先出配对，盈亏记在平仓那一笔上；`盈亏(元) = 权利金价差(点) × 手数 × 合约乘数(元/点)`（如 MO/IO 每点100元、CU 每点5元、AG 每点15元）。乘数优先由结算单反推（\|权利金总额\| ÷ 单价 × 手数），反推失败时查内置乘数表；配对基于**全部历史数据**，即使开仓日在查询窗口之前，跨窗口平仓也能算出正确盈亏 |
| 期权权利金收支 | 现金流口径（买方支出为负、卖方收入为总览参考项），与已实现盈亏分列展示                                                              |
| 总盈亏   | 期货平仓盈亏 + 期权已实现盈亏                                                                                                           |
| 净盈亏   | 总盈亏 - 全部手续费（期货+期权）                                                                                                        |

> 注意：已实现盈亏不含期末未平仓头寸的浮动盈亏；期权明细表中 `open_volume/close_volume`
> 列标出每笔成交的开仓/平仓拆分，期末未平仓手数见查询结果 `opt_open_positions`。

## 鲁棒性说明

- **无成交日**：结算单可以只有资金状况、没有任何成交行，解析不会报错
- **无效结算单文件**（登录过期时监控中心返回 HTML 却存成了 .xls）：自动识别魔数并
  改名为 `.xls.bad` 隔离，下次查询会重新下载，不会反复解析出错
- **长时间区间**：每日趋势返回完整日期（YYYY-MM-DD，跨年不重复），前端图表默认聚焦
  最近 60 个交易日并提供底部滑块，可完整缩放浏览全部区间
- **缺失数据自动补下载**的日期范围不会超出今天；未来日期不会被误判为缺失

## 注意事项

- 本工具仅供个人交易复盘学习使用，请遵守相关法律法规
- 验证码识别使用 ddddocr（基于深度学习的 OCR），准确率约 90%，失败会自动重试
- 结算单文件按日期存储在 `output/` 目录下，已被 `.gitignore` 排除，不会提交到仓库
